Project 5: Spirograph Drawing Machine

This was a really entertaining and interesting project. So I modeled the Spinographs arms hinted by Dr. E's images, and with that I made the rotating base so that it wouldn't just create a circle. I messed around with different speeds of the motors and running them in opposite directions and it created weird and cool patterns as shown in the images and videos. If you couldn't tell from my expressive comments in the videos, messing around with the code would make a limacon for example. As I walked around the room, everyone had different images being drawn so next time if I make this, I want to modify it so that I have the base spin at different speeds or change directions.
